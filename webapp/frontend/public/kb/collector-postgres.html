Collect a PostgreSQL snapshot

pg_collect.py is a single, read-only Python file you run inside your own environment. It produces the snapshot.json you upload for an audit.

Prerequisites

  • Python 3.10 or newer.
  • The PostgreSQL driver: pip install "psycopg[binary]".
  • A read-only database role (see grants below).
  • Recommended: pg_stat_statements enabled — the per-query findings, the most valuable part of the audit, need it.

Minimal read-only grants

The collector reads statistics and catalog views only. A role with the built-in pg_monitor membership is the simplest way to grant exactly what it needs and nothing more: 

CREATE ROLE dbdoctor_ro LOGIN PASSWORD '...';
GRANT pg_monitor TO dbdoctor_ro;

pg_monitor gives read access to pg_stat_* views (including full query-statistics rows) without any access to your table data.

Run it

Download the collector from the New audit page, then:

python pg_collect.py \
  --dsn "postgresql://dbdoctor_ro:PASS@host:5432/yourdb" \
  --out snapshot.json

On success it prints a summary line — how many queries and tables it captured and which capabilities were available: 

wrote snapshot.json  (queries=214, tables=63, capabilities=query_stats,index_usage,...)
Verify what you ran The collector prints its own SHA256 at startup. Compare it against the published hash to confirm the file is unmodified. Because it is a single file with no repo dependencies, you can also read it top to bottom first.

Command-line options

FlagPurpose
--dsnPostgreSQL DSN. May also be supplied via the PGDSN environment variable to keep it out of your shell history. Used for the connection only — never written to the snapshot.
--outOutput file path (default snapshot.json).
--delta-of PREV.jsonDiff against a previous snapshot to add growth/rate fields (useful for tracking change over time).
--keep-namesKeep readable host/database names instead of hashing them to an alias. Off by default — hostnames are hashed unless you opt out.
No query stats yet? If the capabilities line is missing query_stats, pg_stat_statements is not enabled. Follow Enable pg_stat_statements, let a normal workload run for at least a day so statistics accumulate, then re-run the collector.

Keep credentials out of your shell history

export PGDSN="postgresql://dbdoctor_ro:PASS@host:5432/yourdb"
python pg_collect.py --out snapshot.json
