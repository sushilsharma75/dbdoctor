Collect a MySQL / MariaDB snapshot

mysql_collect.py is a single, read-only Python file you run inside your own environment. It produces the snapshot.json you upload for an audit.

Prerequisites

  • Python 3.10 or newer.
  • The MySQL driver: pip install pymysql.
  • A read-only database account (see grants below).
  • Recommended: performance_schema statement digests enabled — needed for per-query findings. On MySQL 5.7/8.0 this is usually on by default; on MariaDB it is usually off.

Minimal read-only grants

CREATE USER 'dbdoctor_ro'@'%' IDENTIFIED BY '...';
GRANT PROCESS, REPLICATION CLIENT ON *.* TO 'dbdoctor_ro'@'%';
GRANT SELECT ON performance_schema.* TO 'dbdoctor_ro'@'%';
GRANT SELECT ON sys.* TO 'dbdoctor_ro'@'%';   -- MySQL only
GRANT EXECUTE ON sys.* TO 'dbdoctor_ro'@'%';  -- sys views call sys functions

Statistics views only — the account never needs SELECT on your data.

Run it

Download the collector from the New audit page, then:

python mysql_collect.py \
  --dsn "mysql://dbdoctor_ro:PASS@host:3306/yourdb" \
  --out snapshot.json

On success it prints a summary line with the captured counts and capabilities:

wrote snapshot.json  (queries=180, tables=41, capabilities=query_stats,...)
Verify what you ran The collector prints its own SHA256 at startup — compare it against the published hash. It is a single file you can read end to end before running.

Command-line options

FlagPurpose
--dsnDSN in the form mysql://user:pass@host:3306/db. May also be supplied via the MYSQL_DSN environment variable. Used for the connection only — never written to the snapshot.
--outOutput file path (default snapshot.json).
--delta-of PREV.jsonDiff against a previous snapshot to add growth/rate fields.
--keep-namesKeep readable host/database names instead of hashing them to an alias. Off by default.

MariaDB caveats

  • performance_schema is off by default on MariaDB — you will almost always need to enable it first. See the enablement guide.
  • The sys schema advisor views (unused/redundant index and full-scan views) do not ship with MariaDB. The collector detects this, continues with reduced capabilities, and notes it in the snapshot; index findings are then derived from index definitions with reduced confidence.
  • Statement latency percentiles (p95/p99) are MySQL 8 only.
No query stats yet? If the capabilities line is missing query_stats, statement digests are off. The collector prints the exact fix; also see Enable performance_schema digests. Let a normal workload run for at least a day, then re-run the collector.
